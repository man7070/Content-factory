# Сотрудники

- `staff.template.csv`: образец, лежит в репозитории.
- `staff.csv`: настоящий список с почтами. В репозиторий НЕ попадает (см. .gitignore).

Роли: Автор брифа, Сценарист, Видеомейкер, Проект-менеджер, AI контент-мейкер, Монтажёр, ОТК, SMM.
Несколько ролей у одного человека пишутся через `;`. `is_chief=yes` у того, кто создаёт брифы и утверждает этапы.

Пароли здесь не хранятся. Каждый сотрудник получает приглашение на почту и сам задаёт пароль и имя.
